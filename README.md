
# Personal Expense Tracker

A web-based Personal Expense Tracker that helps users record, manage, analyze, and monitor their daily expenses.

Features

* Add and manage daily expenses
* Categorize expenses
* Track monthly spending
* Set and monitor monthly budgets
* Get notifications when the budget is exceeded
* View expenses using interactive charts
* View financial summaries and insights
* Download expense reports
* Generate reports containing expense information and visualizations

Technologies Used

* HTML
* CSS
* JavaScript
* MySQL
* Chart.js

 Tools

* Git
* GitHub
* Visual Studio Code

 Project Purpose

The main purpose of this project is to help users manage their personal expenses, monitor spending habits, and understand their financial activity through charts, insights, and downloadable reports.

How to Run

1. Clone the repository.
2. Open the project in Visual Studio Code.
3. Configure the required database settings.
4. Start the application.
5. Open the application in a web browser.
